# RutaFlex · Release 1.2

Carpooling universitario (Universidad de Lima) · Ingeniería de Software II.

```
frontend/   React + Vite (interfaz)
backend/    Supabase: base de datos, API y tiempo real
```

## Pasos

1. **Backend:** ejecutar `backend/supabase/schema.sql` en Supabase → SQL Editor (ver `backend/README.md`).
2. **Frontend:** `cd frontend` → copiar `.env.example` como `.env` con la URL y la key publishable → `npm install` → `npm run dev` (ver `frontend/README.md`).
